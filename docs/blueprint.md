# **App Name**: AnonChat

## Core Features:

- Matchmaking: Connect two random users in a 1-on-1 chat room.
- Text Chat: Real-time text messaging between the two connected users.
- Message Display: Simple UI to send and receive messages.

## Style Guidelines:

- Primary color: Neutral grays for a clean look.
- Secondary color: Soft blues for a calming effect.
- Accent: Teal (#008080) for interactive elements.
- Clean and simple layout with a focus on readability.
- Use minimalist icons for common actions.
